# 设计风格规范（自 Pixso 设计稿提取）

> 来源：Pixso 设计稿 6 屏（引导 / 直播 / 医生列表 / 医生详情 / 预约 / 文章）
> 提取方式：Pixso MCP `get_node_dsl`，全节点样式聚合
> 用途：健康助手 App 的 Flutter Theme 与设计系统基线（与产品健康主题天然契合）

## 1. 色彩系统

| Token | 值 | 用途 |
|---|---|---|
| `primary` | `#27C3B0`（薄荷绿/青） | 主品牌色：选中态、强调文字、按钮、"See all" 链接、标签 |
| `primary.surface` | `#27C3B0` @10% / @5% | 选中标签底色、浅色强调背景（靠透明度分层，不另调色） |
| `text.primary` | `#28332F`（墨绿炭） | 标题与正文主色（非纯黑，带绿灰底调，柔和） |
| `text.secondary` | `#28332F` @50% | 次要信息：日期、作者、辅助说明 |
| `text.tertiary` | `#28332F` @30% | 占位符（Search） |
| `text.disabled` | `#28332F` @10% | 不可用时段（如已过期的预约时间） |
| `background` | `#FFFFFF` | 页面底色（个别页 `#FAFAFA`） |
| `surface` | `#FAFAFA` / `#FFFFFF` | 卡片与浅灰分区 |
| `onPrimary` | `#FFFFFF` @100% | 深色/主色背景上的文字 |
| `accent.warm` | `#FCFF7D`（柠檬黄） | 点缀高亮（直播页医生名，仅 1 处） |
| `accent.danger` | `#FF4747` | 红色警示（仅 1 处） |
| `shadow.tint` | `#062522` @20% | 阴影色调（带品牌绿的投影，非黑影） |

**色彩策略**：双色系（青绿主色 + 墨绿文字）+ 白底，层级全部用主色/文字色的透明度阶梯表达，极少引入新色相——低饱和、医疗感、干净。

## 2. 字体排印

| 级别 | 字体 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|---|
| display | Poppins | 24/36 | 600 | 页面大标题（"doctors in one place"） |
| headline | Poppins | 18/26 | 600 | 数字、卡片标题（"21"、"Book on Appointment"） |
| title | Poppins | 16/24 | 600 | 区块标题、用户名 |
| subtitle | Poppins | 14/22 | 600 | 卡片标题、Tab 文字 |
| body | Poppins | 14/22 | 400/500 | 正文、列表项 |
| caption | Poppins | 12/16 | 400–600 | 辅助说明、标签文字 |
| micro | Poppins | 10/14 | 400/500 | 时间戳、"6 min read"、分类 chip |

- 字体族：**Poppins**（拉丁）；文档可用字体含 **HarmonyOS Sans SC**（中文场景替代）；SF Pro Text 仅状态栏。
- 特点：字号跨度小（10–24），层级靠字重（400/500/600）和颜色透明度区分，不用衬线对比。

## 3. 圆角与形状

| Token | 值 | 用途 |
|---|---|---|
| `radius.sm` | 4 | 小元素、小 chip |
| `radius.md` | 8 | 输入框、小卡片（最高频） |
| `radius.lg` | 16 | 标准卡片、图片容器 |
| `radius.xl` | 24 | 大卡片、弹层、直播卡 |
| `radius.pill` | 100 | 胶囊标签、分类 chip、按钮 |

大圆角策略（8–24 为主），胶囊形 chip 是这套稿的标志性形状。

## 4. 布局与间距

| Token | 值 |
|---|---|
| `space.xs` | 4 |
| `space.sm` | 8 |
| `space.md` | 16 |
| 页面左右边距 | 32（390 宽画板，内容区 326） |
| 画板基准 | iPhone 13 390×844 |

间距体系极简：4 的倍数，8 为主节奏，16 为分区。

## 5. 组件风格特征

- **卡片**：白底 + 8/16/24 圆角，无描边，层级靠圆角与留白（阴影极少且带 `#062522` 绿色调）；
- **分类 chip**：胶囊形，选中态 = 青绿底白字，未选中 = 灰字/浅底；
- **列表项**：左图（66–96px 圆角图）+ 右侧两行文字（标题 + 日期·阅读时间），信息密度低；
- **图标**：Linear 风格线性图标（30×30 触达热区，24×24 视觉），1.5px 左右线宽；
- **状态栏/导航**：极简，返回箭头 + 标题 + More 点，无边框无底色；
- **暗色模式**：设计稿仅浅色（状态栏组件含 DarkMode 标记但全部 False）。

## 6. 对健康助手 App 的适配建议

这套风格与健康助手产品定位高度契合，可直接继承：
- 主色 `#27C3B0` 传递"健康、放松、医疗专业感"，与交互文稿"克制、不恐吓"的原则一致；
- 透明度阶梯文字色正好承载"AI 建议文案（主）+ 动作说明（次）+ 时长（微）"的三级信息；
- 需要补充的 token：成功/完成态色（建议沿用主色而非另加绿色）、提醒频控降级提示色（可用 `#28332F` 50%，避免警告红引发焦虑，与"不恐吓"文案原则对齐）；
- 中文场景字体：HarmonyOS Sans SC 替代 Poppins，数字/英文可保留 Poppins 双字体栈。
