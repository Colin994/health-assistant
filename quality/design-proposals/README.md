# Mobile design proposals

Use one record per design change. Include the affected screens and states, the Pixso file, page and frame IDs, the candidate revision, expected interactions, and shared walkthrough case IDs. Record approval status per screen or state. When explicitly approved, capture the approved revision or snapshot and approval evidence in [the design baseline](../design-baseline.md). Keep the proposal as a record of the change.

Name UI proposals using `UI-NNN · 改动主题` and use the lowercase ticket ID as the filename.
