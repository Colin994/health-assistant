## 2. 2026-11-20 审计发现与「去 AI 化」优化方案

本轮审计重点解决精修初稿中**“过度自解释、表面文字提示泛滥、像 AI 生成说明书”**的问题，遵循《交互设计文档》**“不打扰、零决策成本、克制自然”**的设计原则。

### 2.1 删除视觉控件旁的冗余自解释文字（消除“AI 说明书味”）

1. **`[FIX]` `08 提醒设置` — 移除 3 处 Switch 开关旁的「开启」文字并修复水平碰撞**
   - **现状问题**：「喝水提醒」「护眼提醒」「午休静音」3 个开关左侧均多画了一个 `开启` 文字节点（`x=268, w=38`）。其中「护眼提醒」副标题 `每 20 分钟 · 看向远处 20 秒`（`x=32, w=282`，右边界 `x=314`）与 `开启` 文字及开关触达区在 `x=268~314` 发生 **46px 水平重叠**。
   - **修改规则**：**彻底删除 3 处 `开启` 文字**；将左侧标题/副标题文本框宽度收敛至 `220px`（右边界 `x=252`），与右侧开关（`x=314`）保留 `62px` 安全留白。开关的开启/关闭状态由轨道填充色（开启 `#0B7A6D` / 关闭 `#DFE7E3`）、滑块位置及 Flutter 原生 `Switch` 无障碍语义（`Semantics.toggled`）表达，不在画面上重复写字。
2. **`[OPTIMIZE]` `08 提醒设置` — 移除久坐三档卡片下方的「当前选择：标准」**
   - **现状问题**：上方三档分段卡片（`更严格 45 分钟` / `标准 55 分钟` / `更宽松 75 分钟`）已通过 `#F0F7F5` 浅青绿底 + `#0B7A6D` 深青绿字明确标识当前选中项，下方又在 `y=272` 写了一行 `当前选择：标准`。
   - **修改规则**：**删除 `当前选择：标准`**（如需补充非颜色选中特征，在选中档位卡片上增加 `1.5px` `#0B7A6D` 描边），并将下方分隔线与「喝水提醒 / 护眼提醒 / 免打扰」区块整体上移 `24px`。
3. **`[OPTIMIZE]` `02 首启 · 健康标签` — 移除选中卡片内的「已选」文字**
   - **现状问题**：「颈椎不适」卡片右侧塞入 `已选` 文字（`x=144, y=198`），既显机械又在大字号下挤压标签名称。
   - **修改规则**：**删除 `已选` 文字**；选中态由 `#F0F7F5` 底色 + `#0B7A6D` 文字 + `1.5px` `#0B7A6D` 边框（或右上角精简 `✓` 图标）表达。
4. **`[OPTIMIZE]` `01 / 02 / 03 首启引导` — 将「第 X 步，共 3 步」恢复为轻量进度指示点**
   - **现状问题**：主按钮上方使用表单式文字 `第 1 步，共 3 步`（`y=708`）。
   - **修改规则**：**替换为 3 枚居中进度点**（当前步为 `16×6` 圆角胶囊 `#0B7A6D`，未到步为 `6×6` 圆点 `#DFE7E3`，间距 `8px`），无障碍语义保留 `第 X 步，共 3 步`。

### 2.2 收敛列表右侧泛滥的绿字动词，回归轻量 `›` 导航指示

精修初稿将几乎所有列表跳转箭头 `›` 都换成了 `#0B7A6D` 绿色动词（`查看`、`了解`、`打开`、`进入`、`调整`），导致满屏右侧出现高频绿色文字噪点。按以下规则统一收敛：

| 画板 | 列表项 / 区块 | 原右侧文案 | 修订后右侧表现 | 理由 |
| --- | --- | --- | --- | --- |
| `03 首启 · 通知授权` | 连接智能手表（Pro 预告卡） | `了解` | `PRO` 胶囊徽章 + `›` | 整行点击查看预告说明，无需单独写“了解” |
| `05 拉伸` | `颈部侧拉伸` / `收下巴` / `肩部画圈`（3 行） | 连续 3 个 `查看` | 轻量 `›`（`#5A625F` / 首项 `#0B7A6D`） | 连续 3 个“查看”高度重复；点击动作行即进入动作详情 |
| `07 我的` | `提醒设置` 卡片 | `查看` | `›` (`#5A625F`) | 标准二级页面跳转卡片 |
| `07 我的` | `慢植物花园` 卡片 | `进入` | `›` (`#0B7A6D`) | 整卡即为花园入口，去掉冗余动词 |
| `07 我的` | `健康标签` 区块标题栏 | `编辑` | **保留 `编辑` (`#0B7A6D`)** | 唯一独立于卡片之外的标题栏操作按钮，语义明确 |
| `08 提醒设置` | `静音时段` 卡片 | `调整` | `›` (`#5A625F`) | 点击卡片即调整时间范围，无需写“调整” |
| `09 设置` | `连接智能手表` / `隐私与数据说明` / `重看首启引导` / `拉伸页` | `了解` / `查看` / `打开` / `打开` | 统一改为 `›` (`#5A625F`) | 消除一屏 4 个绿字动词的视觉干扰 |

### 2.3 精简同义反复与说教式文案，收敛重复退出入口

1. **`01 首启 · 产品价值`**
   - **现状问题**：标题 `工作间隙，记得休息` 与副标题 `工作间隙，提醒你活动、喝水和看远处` 连用两次“工作间隙”；下方列表 `久坐：按设置的间隔提醒你活动`、`喝水：到时间提醒你喝水`、`护眼：工作间隙提醒你看向远处` 属于无信息量的同义反复。
   - **修订文案**：对齐《交互设计文档》§3.1 的核心价值表达：
     - 主标题：`工作间隙，记得休息`（右上角保留 `跳过引导`）
     - 副标题：`贴合你的办公节奏，轻声提醒、不打断心流`
     - 三项要点：
       - **`时机准`** — `倒计时到了才提醒，专注时不打扰`
       - **`懂你`** — `结合你的身体状况，给做得到的微练习`
       - **`零负担`** — `久坐、喝水、护眼，每次只需 1 分钟`
2. **`03 首启 · 通知授权`**
   - **现状问题**：顶部副标题 `允许通知后，系统会在提醒时间送达消息` 与卡片下方 `提醒由本机倒计时触发。通知授权用于送达提醒` 重复解释同一件事。
   - **修订文案**：卡片下方改为简短安心提示：**`本地倒计时触发，不采集任何个人健康数据`**。
3. **`05 拉伸`**
   - **现状问题**：同一画面出现 5 个退出/否定动作（右上角 `关闭` + `稍后提醒` + `今天别提醒` + `本次不做` + `关闭此类提醒`），其中右上角 `关闭` 与底部 `本次不做` 语义完全重复；且右上角 `关闭` (`y=48`) 紧贴状态栏电池图标，高于标题 (`y=68`)。
   - **修订规则**：
     - **保留底部「本次不做」作为默认设置**（保持与既有走查用例 `M09` 及 `SkipThisPressed` 扩展点一致）；
     - 底部常驻反馈区收敛层级：主按钮 **`做完了`**（`#0B7A6D` 填充）、次按钮 **`稍后提醒`** 与 **`今天别提醒`**（并排次级按钮）、文本按钮 **`本次不做`**、底部弱化入口 **`不再提醒此类`**（`#5A625F` 文本按钮，替代原带边框按钮「关闭此类提醒」）；
     - 右上角关闭按钮改为 `44×44` 触达区的 **`✕` 图标**（与左侧主标题水平对齐）。
4. **`06 动作详情`**
   - **现状问题**：插画下方只有一句话的动作说明前多加了一个 **`怎么做`** 小标题（`y=424`）。
   - **修订规则**：**删除 `怎么做` 小标题**，将动作要领正文 `缓慢将头侧向右肩，感到左侧颈部轻微拉伸即可。不要用力下压` 与频次 `每侧 2 次` 直接呈现在插画卡片下方，视觉更干净。

### 2.4 视觉 Token 与无障碍对比度修正（`FIX`）

1. **`[FIX]` `04 今日` 与 `04-A 今日 · 步数权限未开启` 底部 TabBar 未选中文字色**
   - **现状问题**：`04 今日` 与 `04-A` 的底部 TabBar 未选中项（`我的`、`设置`）使用了旧色值 `#949997`（白底对比度约 `2.8:1`，不满足 WCAG AA），而 `07 我的` 与 `09 设置` 已使用 `#5A625F`（对比度 `6.3:1`）。
   - **修改规则**：全套画板底部 TabBar 未选中文字统一使用 `text.secondary` (`#5A625F`)。
2. **`[KEEP]` 保留本轮精修中已验证的正向改进**
   - 二级页面（`02`、`03`、`06`、`08`）统一使用左侧 `44×44` 触达区的线性返回箭头；
   - 主填充按钮统一使用 `primary.text` (`#0B7A6D`) 配白字 `#FFFFFF`（对比度 `5.2:1`，过 WCAG AA）；
   - `04 今日` 将「今日步数」「已提醒 / 已完成计数」「下次提醒倒计时」「今日记录」整合为清晰的单列层级，`04-A` 在步数未授权态显示「去设置」。
