# game_art 目录结构

| 目录 | 用途 | 状态 |
|---|---|---|
| `plants/` + `plants_512/` | 植物立绘(5 物种 × 6 阶段) | ✅ 定稿 |
| `scenes/` + `scenes_512/` | 花园背景(晨/午/暮/夜,同构图) | ✅ 定稿 |
| `decor/` + `decor_512/` | 装饰 8 件(围栏/小矮人/石板/吊盆/凉亭/庭院灯/长椅/手推车) | ✅ 定稿 |
| `props/` | 玩法道具(篮子/阳光精灵/金阳光精灵,接阳光玩法用) | ✅ 定稿 |
| `album/` + `album_512/` | 押花册底板模板 | ✅ 定稿 |
| `scenes_iso/` | 2.5D 等距场景四时段(1024×1488,edit_iso B 锚点) | ✅ 定稿 |
| `plants_iso/` | 植物 iso 风(5 物种×6 阶段,入土无盆) | 🔄 生成中 |
| `decor_iso/` | 装饰 iso 风(8 件) | 🔄 生成中 |
| `guides/` | 手写 SVG 引导点/道具(开发占位与兜底) | 占位资产 |
| `tools/` | 出图管线:`qwen_edit_gen.py`(指令编辑,场景默认)、`flux_chain_gen.py`(血系并联)、`flux_batch_gen.py`(通用批量)、`flux_edge_gen.py`(单边 img2img)、`*.workflow.json`(ComfyUI 画布工作流,拖入画布打开) | 工具 |
| `ai_samples/` | 生成过程区(选完即删,常态为空) | 临时(已清空) |
